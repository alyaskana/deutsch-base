# Лесенки по темам грамматики

Подход взят из уроков Deutsch mit Yehor (структура, не контент): тема разбита на 3 коротких урока, в каждом этапе тренируется одна узкая вещь, микс только в конце.

## Готово

- Притяжательные (`possessive-pronouns`): уроки `possessiv-1…3` в «Mein Deutsch», выпущены 2026-11-07, `order` −15…−13.
  1. Чьё (по владельцу, «свой») → mein или meine (сортировка) → Nominativ.
  2. Пары Nom/Akk на одном слове → что меняется в Akk (сортировка) → Akk в предложениях.
  3. Akk или Dat по глаголу/предлогу (сортировка) → окончания Dativ → все падежи.

## Формат

- Урок: `topic` «<Тема> · лесенка», `title` «<Тема по-немецки> N», `sub` начинается с «Шаг N из 3», около 16 заданий (~5–6 мин), 3 этапа из существующих типов (`choice`, `sort`, `type`), код страницы не меняется.
- У каждого этапа своя карточка теории с уникальным `t`: тогда карточка этапа со `sub` показывается перед ним. В `sub` правило в одну строку и разобранный пример; пример не совпадает ни с одним заданием.
- `ru` у каждого предложения (перевод под ним), `n` — пояснение «вопрос → ответ → правило», видно сразу после ответа.
- `type` без `o`: страница сама предлагает шесть форм того же слова (mein/meine/meinen/meinem/meiner/meines), проверить, что подходит ровно одна.
- Этапы — в `data/mein-deutsch-grammar.json`, затем `npm run check` и обновить `lessons/_grammar` (если `at` не меняется, добавить суффикс, иначе приложение не обновит кэш карты).
- Немецкий проверяет редактор-носитель отдельным проходом, QA проходит уроки на ширине 390 px.

## Следующие кандидаты

По `build/status.json`: `wo-wohin` (минимальные пары liegen/legen, stehen/stellen), `noun-gender`, `word-order`.

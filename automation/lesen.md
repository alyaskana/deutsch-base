# Сериал для чтения и фокус дня

В «Mein Deutsch» с версии 72 (2026-11-09). Истории взяты из старой читалки Алины «Lesezeit» (german-reader, 58 историй A1, из них 50 серий «Wie man Deutscher wird»). Она попросила вернуть полезное из Fluent: чтение и ровную смену навыков по дням.

## Серия

Одна серия = один урок на 5–7 минут: 5 слов из текста (`meaning`) → чтение с подсказками по тапу и 4 вопроса (`read`) → 5 пропусков из текста (`cloze`) → 2 фразы от себя (`write`).
У документа поля `serial {id,title,ru,sub,total}` и `ep`. Страница складывает такие уроки в одну строку «Читаем сериал» на главной и в экран со списком серий; отдельных плиток у серий нет.

## Как выпустить новую серию

1. Текст серии лежит в `data/lesen/stories.json` (по порядку `order` в коллекции `wie-man-deutscher-wird`). Сам текст не переписывать, править только явные ошибки.
2. Написать `data/lesen/episodes/NN-<id>.json` по образцу первых трёх: `meaning` (5 слов с примером не из текста), `tr` (перевод абзацев), `qs` (4 вопроса, первый вариант верный, пояснение цитирует текст), `cloze` (5 предложений из текста), `write` (2 задания про неё саму).
3. Редактор-носитель проверяет немецкий, переводы и однозначность вопросов (один круг).
4. `node scripts/lesen.mjs` → `build/lesen/lesen-<id>.json`. Скрипт сам ругается на пропуск без ответа в тексте и на вопросы без пояснения.
5. Озвучка обычным путём (`scripts/tts/collect.py`, `gen.py`, `pack.py`): сначала `audio/lesen-<id>.*` и `_index`, потом урок в `lessons`.
6. Запись «Послушать историю» (Алина просила интонации под сюжет, 2026-11-09): `data/lesen/story/lesen-<id>.json` — история по репликам, как сценка «Слушаем» (`who`, `voice`, `de`, `tag`) плюс `p`, номер абзаца. Рассказчик Adrian, у каждого героя свой голос на весь сериал (Tom — Ben, Mia — Lea; новые герои — новые голоса из `data/hoeren/voices.json`). Теги по сюжету: `[lacht]`, `[überrascht]`, `[schmunzelnd]`. Числа словами, без фона. `python3 scripts/hoer/render.py data/lesen/story/lesen-<id>.json <render>`, прочитать `<id>.check.txt` (если распознавание потеряло слово, перепроверить вторым распознаванием или перезаписать), затем `python3 scripts/lesen-story.py <render> <out> lesen-<id>` и снова `node scripts/lesen.mjs`. В базу: `audio/scene.lesen-<id>.<k>`, потом урок. Около 900 символов ElevenLabs на серию; без подписки серия выходит без этой записи, кнопки тогда просто нет.
7. `LESSON=id npm run smoke` по новому уроку.

Порядок выпуска: держать впереди две непрочитанные серии. Когда у Алины остаётся одна непрочитанная (в `progress.lessons` нет записи для последней выпущенной), «Пополнение» выпускает следующую по порядку. Не больше одной серии в день.

## Фокус дня

В плане на сегодня урок выбирается по виду, которого дольше всего не было в `progress.history`: чтение, слушание, грамматика, из жизни, закрепление занятия (`focusLesson` на странице, вид даёт `lessonKind`). Над уроком подпись «Сегодня чтение» и т. п. Чтобы фокус работал, в каждом виде должен быть хотя бы один непройденный урок: «Пополнение» следит, чтобы не кончались серии и сценки «Слушаем».

# Разбор скриншотов доски

Алина присылает скриншоты доски после урока (и, по возможности, дату урока). Claude:

1. Читает каждый скриншот. Неуверенно разобранный почерк помечает `(?)` в `note_ru`/`answer`.
2. Определяет модуль (тему). Новая тема → `data/modules.json` (level A2, следующий order).
3. Лексика → `data/words.json`; грамматика → ссылки на `data/grammar.json`, новые темы добавляет.
4. Упражнения и домашка (H/A) → `data/tasks.json`; ответы Алины и правки репетитора — в `answer` / `correction`.
5. Правки репетитора → наблюдения `error` (source `lesson` или `homework`, `date` = дата урока); проверенное верное → `correct`; стикеры-затруднения → `struggle` (`tutor_sticker`). Ошибки, которые репетитор не исправила, → `claude_review`.
6. Урок → `data/lessons.json` (дата, модули, темы, назначенная домашка).
7. `npm run check`, коммит «Урок <дата>: <тема>», push.
8. Ответ Алине в 2–3 строки: что добавлено, какая домашка, что изменилось в STATUS.md.

Если дата урока не названа — спросить; если Алина недоступна — сегодняшняя дата с `date_approx: true`.

## Через браузер Алины

Когда Алина пишет «пройдись по доске», Claude открывает доску A2 в её браузере через Claude in Chrome и снимает её сам, по тем же правилам разбора.

- На доске Алина в режиме редактирования: только листать и масштабировать. Не кликать по элементам, не нажимать стрелки (сдвигают выделенное).
- Листать — перетаскиванием полос прокрутки справа и снизу; колесо мыши в Miro масштабирует, а не листает. Масштаб — кнопками − / + внизу справа, 10% удобно для обзора.
- Текст и перо читать через zoom небольших участков (около 250×150 px экрана при 10%).
- Большая часть доски — заготовка репетитора на будущее. Переносить только то, что заполнено или отмечено на уроке.
- В конце закрыть вкладку.

## Что не считать ошибкой

- Существительное с маленькой буквы в ответах на уроке (norden вместо Norden). Решение Алины от 2026-11-04: на занятиях для жизни это прощается, заглавные будем править прицельно позже. Наблюдения на `noun-capitalization` не создавать, пока Алина сама не попросит.

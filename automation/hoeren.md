# Уроки «Слушаем» (подслушанный разговор)

Формат в «Mein Deutsch» с версии 72 (2026-11-09). Алина: аудио очень помогает, голоса нужны как можно более разные, чтобы привыкать к акцентам.

Урок: записанный разговор двух людей на 30–40 секунд → 4 вопроса на понимание (текста не видно, можно переслушать целиком и медленнее) → разбор: текст с переводом, каждую реплику можно переслушать → 5 фраз из разговора на грамматическую цель → «найди в тексте» по тем же фразам.

## Как сделать новую сценку

1. Цель взять из `STATUS.md` (сначала «сложно»). Ситуация из жизни Алины: яхта, кот, поездки, быт.
2. Дописать сценку в `data/hoeren/scenes.json`: `lines` (8–9 реплик, `who`, `voice`, `de`, `ru`, при желании `tag` с эмоцией для v3: `[lacht]`, `[seufzt]`), `qs`, `ch`, `sp`, `gloss` для слов, которых нет в словаре, `bg` (описание фона по-английски или `null`), `order`.
   - Два разных голоса из разных мест из `data/hoeren/voices.json`, чередовать пары и акценты; региональные слова (Servus, Grüß dich, Brezen) уместны и объясняются в `gloss`.
   - В `qs` первый вариант верный, пояснение дословно цитирует реплику (по нему `build.py` находит, какую реплику дать переслушать).
   - В `sp` минимум два Partizip II (или два других верных кандидата) в каждом задании.
3. Редактор-носитель: отдельный агент проверяет немецкий, переводы, однозначность вопросов и вариантов. Правки внести до озвучки.
4. `python3 scripts/hoer/render.py <сценка.json> <out>` — один файл на сценку. Делает запись (ElevenLabs text-to-dialogue, `eleven_v3`), фон, сводит и проверяет распознаванием: `<id>.check.txt`. Если голос сказал иначе (например, `hab` вместо `habe`), поправить текст сценки под запись или перезаписать.
5. `python3 scripts/hoer/build.py data/hoeren/scenes.json <out> <db> [id…]` → `db/lessons/<id>.json` и `db/audio/scene.<id>.<k>.json`.
6. Записать в базу «Mein Deutsch»: сначала `audio/scene.*`, потом урок в `lessons`. Отдельные фразы и слова урока озвучить обычным порядком (`scripts/tts/README.md`), имена и междометия не озвучивать.
7. Добавить этапы в `data/mein-deutsch-grammar.json` (этапы 2 и 3), прогнать `npm run check` и `LESSON=id npm run smoke` по новому уроку.

Расход: сценка около 600 символов плюс фон. Когда подписка ElevenLabs закончится, новые сценки сделать нельзя (у OpenAI нет диалогов несколькими голосами), готовые остаются в базе.

# Перенос редизайна «Мозаика» в Mein Deutsch

Страница приложения живёт в артефакте, поэтому перенос сделан скриптом, который накладывается на свежую копию живой страницы.

1. Прочитать живую страницу (Artifact read) и сохранить как `base.html`.
2. `python3 redesign/apply.py base.html out.html` (стили берутся из `redesign/milk.css`).
3. `npm run page-check -- out.html` и `npm run smoke -- out.html папка-с-уроками`.
4. `node redesign/screens.mjs out.html папка-с-уроками shots "showHome()" "showVocab()" …` снимает экраны 390 px.
5. Опубликовать `out.html` в тот же артефакт.

Каждая замена в `apply.py` проверяет, что исходный фрагмент найден ровно один раз. Если страницу изменили другие задачи, скрипт остановится на несовпавшем фрагменте.

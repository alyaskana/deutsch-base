# deutsch-base

Структурированная база изучения немецкого (A1 → A2): что пройдено, что на изучении, что даётся сложно.
Формат рассчитан на чтение кодом и другими моделями.

## Сущности

| Файл | Что хранит | Ключ |
|---|---|---|
| `data/grammar.json` | Грамматические темы: правило, примеры, связи | `id` (kebab-case, `dativ-pronouns`) |
| `data/words.json` | Слова и фразы: артикль, мн. ч., управление, формы | `id` (`w-spiegel`, `w-abholen`) |
| `data/modules.json` | Модули доски Miro (источник материала) | `id` (`wohnen`) |
| `data/lessons.json` | Журнал уроков | `id` = дата `YYYY-MM-DD` |
| `data/tasks.json` | Домашка и упражнения | `id` (`t-wohnen-superlativ`) |
| `data/verb-lists.json` | Списки глаголов на три формы: что спрашивает репетитор (приоритет) и вся таблица A1 по звуковым группам; какие уроки «Mein Deutsch» их тренируют | `id` (`tutor-drei-formen`) |
| `data/observations.jsonl` | События: ошибка, верный ответ, сложно. По одной записи на строку, только дописывается | `id` (`o-2026-10-09-001`) |

Связи — только через `id`. Схемы каждого файла в `schema/`.

## Главный принцип

Статус темы или слова **не хранится**, а вычисляется из `observations.jsonl`.
В базу записываются факты, выводы считает код. Наблюдения пишут Claude (при разборе урока или домашки) и тренажёры.
Каждое наблюдение ссылается на источник: `task` → задание с твоим ответом, правкой репетитора и вкладкой архива; `lesson` → урок. Так от любой ошибки можно дойти до оригинала. Наблюдение без даты считается давним: остаётся в истории, но не влияет на окно 21 день. Отметка репетитора (`flagged`) действует, пока после неё не накопится 3 верных ответа с датой.

### Правила статуса

Для каждой цели (`target`) берутся её наблюдения, отсортированные по дате.

| Статус | Условие |
|---|---|
| `new` | наблюдений нет: материал встречался, но знание не проверялось |
| `stuck` | за последние 21 день ≥ 2 записей `error`/`struggle`, **или** `flagged` от репетитора и после него < 3 `correct` с датой позже отметки |
| `solid` | последние 5 записей — `correct`, между первой и последней из них ≥ 7 дней, за 21 день нет `error` |
| `learning` | всё остальное |

Пороги вынесены в `schema/status-rules.json`, чтобы их можно было менять без правки кода.

## Источники наблюдений (`source`)

- `tutor_sticker` — стикер репетитора с затруднением после урока
- `tutor_review` — устная оценка репетитора (например, ревью A1 в октябре)
- `homework` — проверенная домашка
- `lesson` — ошибка или успех на уроке
- `chat` — практика с Claude
- `claude_review` — ошибка на доске, которую репетитор не исправила, а заметил Claude
- `trainer:<name>` — тренажёры (`trainer:artikelregen`, `trainer:mein-deutsch`, `trainer:padezh`)

## Связь с другими местами

- `TEAM.md` — устав команды: роли, порядок работы и проверки перед выпуском уроков и тренажёров.
- `build/dict.json` — словарь для раздела «Словарик» в «Mein Deutsch» (`npm run dict`, входит в `npm run check`): слова с уроков из `words.json` и общая лексика A1–A2 из `data/catalog.txt`, по темам-плиткам. Приложение берёт его из своей базы (`lessons/_dict`), копия встроена в страницу. Темы, цвета и маскоты тем задаются в `scripts/dict.mjs`.
- `build/grammar-map.json` — карта грамматики A1–A2 для раздела «Грамматика» в «Mein Deutsch» (`npm run grammar-map`, входит в `npm run check`): темы верхнего уровня со статусами, правилом, подтемами, занятиями репетитора и этапами уроков. Приложение берёт её из своей базы (`lessons/_grammar`). Какие этапы уроков тренируют какую тему — `data/mein-deutsch-grammar.json`: каждый новый урок «Mein Deutsch» добавляет туда свои этапы, иначе он не попадёт в «Закрепить». Темы A2, которые ещё не проходили, лежат в `grammar.json` с `planned: true` и статусом «впереди»; первое наблюдение по теме снимает эту отметку. `short` — подпись клетки в таблице.
- `design/README.md` — где лежит дизайн-система «Дизайн Mein Deutsch»: стиль, UI-кит, иллюстрации, журнал решений.

- Доска Miro «Deutsch A1 — Alina» — первоисточник уроков.
- Claude Doc «Немецкий A1 — база пройденного» — архив доски в читаемом виде.
- Тренажёры читают `words.json` и `grammar.json` и пишут в `observations.jsonl`.

## Как пользоваться

```bash
npm install
npm run check        # проверить схемы и ссылки, пересчитать статусы
```

- `STATUS.md` — сводка для чтения: что даётся сложно, что изучается, что уверенно.
- `build/status.json` — то же для кода и моделей.
- Новое наблюдение — строка в конец `data/observations.jsonl`, затем `npm run check`.

## Происхождение данных

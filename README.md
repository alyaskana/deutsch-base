# deutsch-base

Структурированная база изучения немецкого (A1 → A2): что пройдено, что на изучении, где затыки.
Формат рассчитан на чтение кодом и другими моделями.

## Сущности

| Файл | Что хранит | Ключ |
|---|---|---|
| `data/grammar.json` | Грамматические темы: правило, примеры, связи | `id` (kebab-case, `dativ-pronouns`) |
| `data/words.json` | Слова и фразы: артикль, мн. ч., управление, формы | `id` (`w-spiegel`, `w-abholen`) |
| `data/modules.json` | Модули доски Miro (источник материала) | `id` (`wohnen`) |
| `data/lessons.json` | Журнал уроков | `id` = дата `YYYY-MM-DD` |
| `data/tasks.json` | Домашка и упражнения | `id` (`t-wohnen-superlativ`) |
| `data/observations.jsonl` | События: ошибка, верный ответ, затык. По одной записи на строку, только дописывается | `id` (`o-2026-10-09-001`) |

Связи — только через `id`. Схемы каждого файла в `schema/`.

## Главный принцип

Статус темы или слова **не хранится**, а вычисляется из `observations.jsonl`.
Руками пишутся факты («ошибка в wo/wohin в домашке 12.10»), выводы считает код.

### Правила статуса

Для каждой цели (`target`) берутся её наблюдения, отсортированные по дате.

| Статус | Условие |
|---|---|
| `new` | наблюдений нет, но тема/слово уже встречались в модуле |
| `stuck` | за последние 21 день ≥ 2 записей `error`/`struggle`, **или** `flagged` от репетитора и после него < 3 `correct` |
| `solid` | последние 5 записей — `correct`, между первой и последней из них ≥ 7 дней, за 21 день нет `error` |
| `learning` | всё остальное |

Пороги вынесены в `schema/status-rules.json`, чтобы их можно было менять без правки кода.

## Источники наблюдений (`source`)

- `tutor_sticker` — стикер репетитора с затруднением после урока
- `tutor_review` — устная оценка репетитора (например, ревью A1 в октябре)
- `homework` — проверенная домашка
- `lesson` — ошибка или успех на уроке
- `chat` — практика с Claude
- `trainer:<name>` — тренажёры (`trainer:artikelregen`, `trainer:mein-deutsch`, `trainer:padezh`)

## Связь с другими местами

- Доска Miro «Deutsch A1 — Alina» — первоисточник уроков.

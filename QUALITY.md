# Стандарт качества

Принят 8 ноября 2026, одобрен Алиной. Полная версия с примерами: Claude Doc «Стандарт качества Mein Deutsch» https://claude.ai/artifact/6QzSu9uUWDYJF3Azm94eDQ

Планка одна: результат, за который не стыдно перед заказчиком. «Работает» — это минимум, а не готовность.

## Почему раньше не получалось

1. Проверяли, работает ли, а не как выглядит и читается. На скриншот глазами дизайнера никто не смотрел.
2. Добавляли, а не отбирали: четыре «начать» на главной, многословные ответы ИИ, списки в карточках.
3. Украшали без смысла: случайный цвет, бейджи, маскоты, видимые цифры клавиш.
4. Угадывали вместо сверки: пропуски из Miro, ударения, обещания до того, как заработало.
5. Брали референс целиком или крутились вокруг одного варианта; делали сложное раньше базового.
6. Все роли — один исполнитель за один проход. Независимой проверки не было.

## Вкус Алины

Эстетика и вайб в приоритете, удобство не жертвуется. Цвета, шрифты и настроение Mein Deutsch не меняются. Из референсов берутся отдельные приёмы, а не стиль целиком.

| Нравится | Отвергнуто |
| --- | --- |
| Текущий стиль Mein Deutsch | Бумажный коллаж, тетрадь «в лоб» |
| Плитки и свайп как в Drops | «Унылые» списки и формы |
| Один план дня, крупно следующий шаг | Несколько «начать» в разные места |
| Таблица тем, путь по занятиям | Нагромождённое оглавление |
| Цвет со смыслом (род, тип урока) | Цвет, бейджи, маскоты «для красоты» |
| Ответ по делу: die Schildkröte + пример | Пояснения не по делу |
| Правки прямо в тексте (Writty) | Красный фон на не-ошибках |
| Обзор красиво в приложении | Сухие отчёты в чате |
| Идеи из её жизни: репетитор, ситуации, ритм | Календарь, ужин, бот, перехват рилсов |
| Взрослые подробные иллюстрации (Canva) | Детский стиль, рисунки кодом |
| «Сложно» | «Затык», жаргон, видимые клавиши |

## Правила интерфейса и текста

1. Одно главное действие на экран.
2. Карточка на главной: подпись, один факт, одно действие. Подробности на своём экране. Новое на главной только вместо чего-то.
3. Каждый цвет, бейдж, иконка, маскот что-то значит, и это читается без легенды.
4. Только токены и компоненты UI-кита; новый компонент сначала в кит.
5. Всё на сетке, заголовки заметные, отступы в одном ритме, цвета не спорят.
6. Ничего служебного на виду.
7. Сначала базовое (таблица, справка), потом тренировки.
8. ИИ отвечает только на вопрос. Красный только для настоящих ошибок.
9. Пустые и крайние состояния: одна фраза и следующий шаг.
10. Текст простой и спокойный, заголовок 1–3 слова, подпись в одну строку.
11. Алине: результат, скриншот, одна строка о проверке. Обещаем только работающее. Что можем сделать сами, делаем сами.

## Проверки

Перед публикацией — пять пунктов из `TEAM.md` («Проверки перед публикацией»): `page-check`, `smoke`, взгляд автора на скриншот телефона, проверка немецкого, ревьюер только для нового экрана, формата или вариантов. Шестая причина из списка выше («нет независимой проверки») теперь закрыта автотестом: он независим от автора и не устаёт.

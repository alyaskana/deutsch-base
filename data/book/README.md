# Книга «Немецкий от А до Ja!» в Mein Deutsch

Книга Егора Чулкова (Deutsch mit Yehor), куплена Алиной для личного использования. Epub лежит в файлах проекта: `/mnt/project-files/kniga/`.

Решения Алины (2026-11-13):
- книга — раздел «Книга» внутри Mein Deutsch (вход на вкладке «Уроки»), не отдельное приложение;
- один подраздел книги (6.7, 15.2…) = один урок в приложении, сколько бы он ни занял;
- A1 проходим быстро через «Проверь себя» и контрольную, хвосты закрываем, дальше A2 по порядку;
- старый раздел «Грамматика» сливается с книгой: книга — основа, статусы тем, «Закрепить» и «Где было» переходят на её разделы (в работе).

## Файлы

- `structure.json` — оглавление: части A1–C2, 60 уроков с подразделами, номера видео плейлиста «Грамматика 2.0» к уроку (`v`), сами видео (`videos`: номер → id YouTube, название; у 17–19 встраивание запрещено автором). Собирается из epub скриптом, вшит в страницу константой `BOOK`.
- `units/book-NN-S.json` — уроки-разделы. Лежат в коллекции `lessons` артефакта под тем же id.

## Урок-раздел

Обычный урок Mein Deutsch (`title`, `topic`, `sub`, `stages`) плюс поле `book`:

```json
"book": {"l": 6, "s": "6.7", "video": {"n": 26, "t": 76, "end": 287, "cap": "FUDOG: пять предлогов с Akkusativ"}}
```

`th` — теория раздела текстом книги (Алина, 2026-11-14: «не стоит сильно отходить от книги», оформление можно улучшать). Собирается из epub: `python3 -I scripts/book-theory.py <OEBPS> <урок> <раздел> data/book/units/book-NN-S.json`. Узлы по порядку книги: подзаголовок, абзац (немецкое жирным), таблица, примеры, рисунок (data:), рамки «Запомните»/«Ловушка». Рамки «Немецкий в русском», «Австрия и Швейцария», «Ложные друзья» уходят в `extra` (блок «Интересное из урока» после теории). `sum` — «Коротко о главном» по разделу, 3–4 пункта, пишем сами; показывается до теории. После скрипта — разметка вручную, текст не меняем: подзаголовки по смысловым кускам, полные немецкие предложения-примеры карточками `ex`, абзац-предостережение рамкой `trap`, рамку рядом со своим правилом, рисунок к своим примерам, рамки не по теме раздела — в `extra`. Страница выносит целые немецкие предложения «<b>Фраза из 4+ слов</b> (перевод)» карточками под абзацем, короткие сочетания остаются в тексте. Подсветку и плашки Алина отклонила (2026-11-14: «не прям настолько много оформления», нравилось оформление v131 — подзаголовки, таблицы, карточки примеров, рамки). Экран раздела: «Коротко» → теория → интересное → видео → упражнения; «?» в заданиях открывает теорию, если у этапа нет своей.

`l` — урок книги, `s` — подраздел, `video` — номер видео в плейлисте, секунда начала и конца отрывка (из оглавления в описании видео), подпись. Видео в артефакт не встраивается: страница даёт ссылку `youtu.be/ID?t=сек`.

Содержание: немецкие примеры и упражнения берём из раздела книги и её ключа, объяснения пересказываем коротко и своими словами. Типы этапов и проверка заданий — как в `automation/popolnenie.md` (ровно один верный ответ, проверка носителя). После записи урока — строки в `data/mein-deutsch-grammar.json` и `npm run check`.

YouTube из облака закрыт: оглавление видео читать через Claude in Chrome (`oembed` и `watch?v=` с youtube.com).

## Практика урока, «Проверь себя», словарь (2026-11-14)

- `units/book-NN-P.json` — «Практика урока»: все упражнения урока из книги (`book.s = 'N.P'`, `kind: 'P'`), ответы и пояснения из ключа. `units/book-NN-C.json` — «Проверь себя» (`'N.C'`, `kind: 'C'`). Генерирует `scripts/book-practice.py <OEBPS> <урок> <outdir>`: варианты → choice, пропуски → type (несколько пропусков дробятся, следующие не подсказываются), перевод → build, записка → write.
- Упражнения с аудио: реплики по «Тексту записи» из ключа в `listen/<id>.scene.json` (голоса разных регионов), озвучка `scripts/hoer/render.py`, этапы listen + script вставляет `scripts/book-listen.py`; звук в коллекции `audio` (`scene.book-NN-K.*`).
- `vocab/NN.json` — «Словарь урока» (`scripts/book-vocab.py <OEBPS> <урок>…`). `scripts/dict.mjs` делает из каждого урока тему словарика «Книга · урок N» (ключ темы — символ U+0100+N); на главной словарика они в блоке «Из книги», в уроке книги — строка «Словарь урока».
- В разделах книги нет разминки из повторов (Алина: урок строго по книге).
- Уроки 1–5: только теория, без упражнений (Алина: темы уже понятны).

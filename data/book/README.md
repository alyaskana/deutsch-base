# Книга «Немецкий от А до Ja!» в Mein Deutsch

Книга Егора Чулкова (Deutsch mit Yehor), куплена Алиной для личного использования. Epub лежит в файлах проекта: `/mnt/project-files/kniga/`.

Решения Алины (2026-11-13):
- книга — раздел «Книга» внутри Mein Deutsch (вход на вкладке «Уроки»), не отдельное приложение;
- один подраздел книги (6.7, 15.2…) = один урок в приложении, сколько бы он ни занял;
- A1 проходим быстро через «Проверь себя» и контрольную, хвосты закрываем, дальше A2 по порядку;
- старый раздел «Грамматика» сливается с книгой: книга — основа, статусы тем, «Закрепить» и «Где было» переходят на её разделы (в работе).

## Файлы

- `structure.json` — оглавление: части A1–C2, 60 уроков с подразделами, номера видео плейлиста «Грамматика 2.0» к уроку (`v`), сами видео (`videos`: номер → id YouTube, название; у 17–19 встраивание запрещено автором). Собирается из epub скриптом, вшит в страницу константой `BOOK`.
- `units/book-NN-S.json` — уроки-разделы. Лежат в коллекции `lessons` артефакта под тем же id.

## Урок-раздел

Обычный урок Mein Deutsch (`title`, `topic`, `sub`, `stages`) плюс поле `book`:

```json
"book": {"l": 6, "s": "6.7", "video": {"n": 26, "t": 76, "end": 287, "cap": "FUDOG: пять предлогов с Akkusativ"}}
```

`l` — урок книги, `s` — подраздел, `video` — номер видео в плейлисте, секунда начала и конца отрывка (из оглавления в описании видео), подпись. Видео в артефакт не встраивается: страница даёт ссылку `youtu.be/ID?t=сек`.

Содержание: немецкие примеры и упражнения берём из раздела книги и её ключа, объяснения пересказываем коротко и своими словами. Типы этапов и проверка заданий — как в `automation/popolnenie.md` (ровно один верный ответ, проверка носителя). После записи урока — строки в `data/mein-deutsch-grammar.json` и `npm run check`.

YouTube из облака закрыт: оглавление видео читать через Claude in Chrome (`oembed` и `watch?v=` с youtube.com).
